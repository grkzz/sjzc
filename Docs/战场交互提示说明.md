# 战场交互提示

## 可放位置

点击手牌或向上拖起手牌时，绿色边框标出合法目标。拖动到合法目标时会显示“松开放置”，蛋卡显示半透明落位预览。点击选牌时显示“点击确认”。

敌方区域、未开放格位、占用格位、错误区域和不符合道具条件的位置不会作为合法目标。移到这些位置会显示红框、不可放置标签和具体原因。松手失败不消耗卡牌。预览图片沿用当前参考卡面，真正落位后使用卡牌预设体。

道具按当前战斗规则匹配：水枪和折纸选已有蛋，特殊工艺选已有怪兽，复活币需有阵亡记录和空怪兽位。抽卡道具可直接点按使用。效果规则与之前版本一致。

## 就绪蛋

己方回合中，归零的蛋出现青色呼吸边框、“可孵化”和轻微跳动的“点击孵化”标识。下方提示当前就绪数量。

选中就绪蛋后，己方已开放的空怪兽位发光；选择位置即可孵化。怪兽位已满时不会显示可落位目标。保留就绪蛋继续等待仍可积攒蕴灵。

## 独立状态栏

完整原卡图保持不变，实战信息位于卡外的深色两行状态栏：

- 怪兽第一行：黄色“攻”与攻击力、粉色爱心与当前生命。
- 怪兽第二行：♂/♀ 性别、一至三阶或霸主、✦ 总蕴灵（含光环）。
- 蛋第一行：剩余计时或“可孵化”。
- 蛋第二行：阶级、✦ 自身蕴灵。
- 当前可攻击的己方怪兽上方显示“可攻击 ×次数”和金色边框；选中后可攻击的敌兽显示目标边框。

图标受项目现有字体支持范围限制，攻击采用文字标识保证清楚。精确最大生命、自身与光环蕴灵分解、代数、候选概率等仍可在大字号详情中查看。

## 验证方式

复用 StandaloneInputModule 的完整鼠标按下/移动/松开流程，检查选牌、拖牌、错误落点不耗卡、横向浏览、下方玩家区域归属、合法/敌方/锁定/错误区域目标、道具无效目标、就绪蛋提示、孵化空位及 AI 回合提示隐藏，并完成整场对局。

截图与日志位于 Logs/FeedbackVerified*。Windows 使用 Builds/PerspectiveWindows/ShenYiPerspective.exe。Unity 需退出 Play 并重新进入，已经启动的独立程序需重开。
