# 卡牌可视化编辑器

在 Unity 2022.3 中打开本工程，等待脚本编译完成，菜单选择 **神奕战场 → 卡牌可视化编辑器**。

窗口左侧是卡牌库，中间是真实 UGUI 渲染的卡面预览，右侧是卡牌信息、图层和属性。编辑草稿不会立即修改原预设体；点“保存”后才写入资源。

## 修改现有卡牌

1. 点击左侧卡牌名称；也可从 Project 将卡牌 prefab 拖到左下方“打开”栏，或者右键 prefab 选择“用卡牌可视化编辑器打开”。双击带 CardPrefabView 的 prefab 也能打开工具。
2. 在右侧选中图片图层，将 Project 中的图片拖到“图片 PNG”。素材需先放到工程 Assets 下。
3. 在预览区点击图层并拖动位置，拖动选框右下角调整尺寸；按住 Shift 移动可按 10 像素吸附。右侧“位置 / 尺寸”可精确填写设计坐标，原点在卡面左上角。
4. 文字图层可以修改显示文字、字号、字体、对齐、字形、颜色和透明度。文字支持换行。
5. 点“保存”或 Ctrl+S 覆盖当前 prefab，点“另存新卡”保存独立副本。切换卡牌时，有未保存修改会提示保存、放弃或取消。

Unity 菜单 Edit → Undo / Redo 可撤销、重做图层和属性操作。编辑时请退出 Play 模式。

## 新建卡牌

- **新建完整卡面**：适合目前提供的整张 PNG。替换一个图片图层即可，默认 600 × 800，保持 3:4。原图的文字、装饰与卡框全部保留。整张 PNG 上已经印好的文字需要修改源图；工具不能把这些像素拆成独立文字层。
- **新建分层卡牌**：提供底色、插画、卡名、属性、效果、攻击、生命等独立示例图层。可以替换插画、添加透明卡框 PNG、编辑文字。分层示例是工具功能演示，正式外观可由美术自行配置。

右侧“+ 图片 / + 文字 / + 色块”可添加图层。列表下方的图层绘制在上方。支持隐藏、复制、删除和调整层级；“按图片比例适配设计区”会完整显示图片。

“导出 PNG”可导出当前卡面截图，便于美术审阅；游戏使用的是 prefab，导出 PNG 不是保存 prefab。

## 资源与游戏接入

示例 prefab 位于 `Assets/_Game/Resources/CardPrefabs/`：

| 文件名 | 用途 |
| --- | --- |
| egg_fire.prefab | 默认单属性蛋卡 |
| egg_dual.prefab | 默认双属性蛋卡 |
| monster_fire.prefab | 默认怪兽卡 |
| monster_dual.prefab | 默认双属性怪兽卡 |
| monster_grass.prefab | 默认草属性怪兽卡 |
| layered_example.prefab | 分层编辑示例，不自动参与对局 |

前五张使用提供的完整卡图。修改后退出 Play、重新运行对局，即可在手牌与棋盘上看到保存结果。已发布的 Windows 程序需要重新构建，才会包含后续保存的修改。

也可为某个具体卡牌指定外观：在上述文件夹另存 prefab，文件名使用 `egg_配置ID` 或 `monster_配置ID`。例如 `egg_fire_triangle.prefab`、`monster_triangle.prefab`。文件名决定运行时查找；建议卡牌 ID 与文件名一致。配置 ID 来自 `Assets/_Game/Resources/Prototype/PrototypeData.json`。具体外观不存在时自动使用默认样例。繁殖出的蛋按核心怪兽匹配现有蛋配置。

卡牌 prefab 中保留标准 UGUI 图片、文字节点，可在 Unity 中正常引用。根节点额外添加的美术子物体会保留；`__CardVisuals` 是工具自动生成的外观区，保存时会重建，请在可视化工具中编辑这部分。工具打开的是带 `CardPrefabView` 的卡牌 prefab，任意其他 prefab 不会自动转换。

这里编辑的是**外观**。攻击、生命等文字是卡面显示内容，真实战斗数值和技能仍由 PrototypeData.json 与战斗逻辑决定。当前完整素材卡仅用于模拟，印刷内容可能与实战数值不同，以卡下实时状态及详情中的规则数据为准；详情大图仍展示原始参考卡面。

## 验证

菜单 **神奕战场 → 卡牌工具 → 运行保存与预览自检** 可检查保存、覆盖、另存、重新打开、图片与文字引用、布局、自定义节点保留和实际预览渲染，报告位于 `Logs/CardPrefabEditorChecks.txt`。检查临时卡牌会自动清理，不覆盖已有美术修改。

“补充示例预设体（保留已有修改）”只创建缺失的示例文件，已有示例不会重置。
